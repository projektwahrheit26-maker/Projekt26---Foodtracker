Projekt26 FoodTracker - GitHub Pages
1. Neues öffentliches GitHub-Repository erstellen (z.B. projekt26-foodtracker).
2. index.html und manifest.webmanifest in die oberste Ebene hochladen.
3. Settings > Pages > Deploy from a branch > main / (root) > Save.
4. Einige Minuten warten und die angezeigte Pages-Adresse auf dem Handy öffnen.
5. In Chrome: Menü (drei Punkte) > Zum Startbildschirm hinzufügen.

WICHTIG: Nur die App-Dateien auf GitHub hochladen, niemals exportierte Ernährungstagebücher/JSON-Sicherungen.
Die Daten bleiben lokal im jeweiligen Browser; bitte regelmäßig JSON-Sicherungen herunterladen.
Die Open-Food-Facts-Suche benötigt Internet und kann bei API-Änderungen/Netzwerkfehlern ausfallen.
